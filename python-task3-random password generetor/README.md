# Task 3 - Random Password Generator

## Project Description

This project is a Python-based Random Password Generator. It generates strong random passwords according to the user's selected length and character types.

## Features

- Allows the user to choose password length
- Minimum password length of 8 characters
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Requires at least 2 character types
- Validates user input
- Generates a random password
- Ensures selected character types are included
- Allows the user to generate another password without restarting

## Technologies Used

- Python
- random module
- string module

## Character Types

The user can select:

1. Uppercase letters (A-Z)
2. Lowercase letters (a-z)
3. Numbers (0-9)
4. Symbols

At least two character types must be selected.

## How to Run

1. Open the project in PyCharm.
2. Open the Python file.
3. Run the program.
4. Enter the desired password length.
5. Select at least two character types.
6. The program will generate a random password.
7. Choose whether to generate another password.
