# Task 2 - BMI Calculator

## Project Description

This project is a simple Python BMI Calculator. It takes the user's weight and height, calculates the Body Mass Index (BMI), and displays the BMI category.

## Features

- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI up to 2 decimal places
- Classifies BMI as:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Validates user input
- Rejects negative weight
- Rejects negative height
- Rejects zero height
- Handles invalid numeric input

## Technologies Used

- Python
- input()
- Basic arithmetic
- Conditional statements
- Exception handling

## BMI Formula

BMI is calculated using:

BMI = Weight / (Height × Height)

## How to Run

1. Open the project in PyCharm.
2. Open the Python file.
3. Run the program.
4. Enter your weight in kilograms.
5. Enter your height in meters.
6. The program will display your BMI and category.

## Example

Enter your weight in kg: 60

Enter your height in meters: 1.65

Your BMI is: 22.04

Category: Normal
